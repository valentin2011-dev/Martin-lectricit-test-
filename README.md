# Martin Électricité — V1

Prototype React/Vite responsive pour la gestion de clients, interventions, devis, statistiques et paramètres.

## Lancer

```bash
npm install
npm run dev
```

## Inclus
- Dashboard
- Clients + recherche + fiches
- Interventions
- Devis
- Génération PDF locale
- Statistiques
- Paramètres / thème sombre
- Navigation mobile
- Persistance de démonstration avec localStorage

## À faire avant une vraie livraison client
Remplacer localStorage par une base distante et ajouter authentification, isolation des données par compte, sauvegardes serveur, email réel, relances automatiques, stockage du logo et hébergement HTTPS.
